# Лабораторная работа № 2 — вариант 6

Реализован [бэкенд на FastAPI](backend/README.md) для генерации случайных чисел через WebSocket. Flutter-клиент пользователь разрабатывает отдельно. Для полной сдачи лабораторной необходимо подключить мобильное приложение на ОС Аврора к серверу ПК в локальной сети.

В `backend` находятся исходники, комментарии, тесты и консольная проверка сокета. Первая лабораторная независима от этого проекта.
