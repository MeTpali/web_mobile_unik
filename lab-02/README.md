# Лабораторная работа № 2 — вариант 6

Генератор случайных целых чисел: [Python-сервер](backend/README.md) и [Flutter-клиент для Авроры](calculator/README.md).

Клиент задаёт диапазон, отправляет запрос через WebSocket и отображает результат, ошибки и историю. Адрес ПК в локальной сети задаётся в интерфейсе. Для полной сдачи требуется демонстрация на устройстве под ОС Аврора.
