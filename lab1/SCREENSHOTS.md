# Снимки для отчёта по ЛР1 · вариант 6

Номера ниже совпадают с разделом 2.5 в `../reports/Отчёт_ЛР_01.md` и DOCX. Лабораторная оформляется одним отчётом. В задании количество фотографий не установлено; ниже оставлен компактный набор для явно требуемых демонстраций. Реализация async/@media, JSON, HTTP-заголовков, авторизации и кэширования также описана в тексте и листингах отчёта; отдельные фотографии кода не нужны.

## Как снимать и сохранять

1. На ноутбуке используйте штатный инструмент снимков экрана. Экран телефона фотографируйте другим устройством: держите камеру параллельно экрану, уберите блики, дождитесь фокусировки. Проверьте читаемость текста перед переходом к следующему состоянию.
2. Создайте каталог `docs/screenshots/manual/` внутри этой лабораторной. Сохраняйте PNG или JPG с именами из шагов ниже. Если нужны два кадра, добавляйте `-a`, `-b`; например `lr2-03-mobile-crud-a.jpg`. Обычно достаточно одного кадра на рисунок; два кадра нужны только для CRUD на телефоне в ЛР2.
3. В кадре оставляйте нужную форму, результат, статус или терминальную команду. Пароль должен быть скрыт; JWT и секреты сервера не снимайте. Скрин с пустой формой или только запущенным сервером не заменяет результат действия.
4. В DOCX замените строку `[Место для изображения: …]` соответствующим фото через «Вставка → Изображения», сохранив подпись ниже. При нескольких кадрах вставьте их под одной подписью. В Markdown замените строку ссылками вида `![Описание](../lab1/docs/screenshots/manual/ИМЯ.jpg)`.
5. Делайте кадры только после получения описанного результата. Если он отличается, сначала разберитесь с ошибкой. Сырые фотографии храните вместе с проектом. После ручного заполнения отчётов не запускайте генератор без резервной копии: он создаёт отчёты заново с пустыми местами.

## Подготовка

Команды ниже предполагают, что зависимости и приложения уже установлены. Для установки с нуля используйте `README.md` и `DEMONSTRATION.md` этой лабораторной.

Определите текущий адрес ноутбука командой `ip -4 addr`. Далее `IP_ПК` заменяйте реальным адресом, доступным телефону. SSH-адрес телефона `192.168.2.16` не является адресом сервера. Ноутбук и телефон должны иметь сетевой маршрут друг к другу. Если порт занят, проверьте уже работающий сервер, прежде чем запускать второй.

В первом терминале:

```bash
cd ~/Unik/web_mobile_unik/lab1/lab-01
npm run build
npm start
```

Страница ноутбука: `http://127.0.0.1:3000/`; телефона: `http://IP_ПК:3000/`. Во втором терминале:

```bash
cd ~/Unik/web_mobile_unik/lab1/lab-02/backend
.venv/bin/python run.py
```

Flutter-приложение можно открыть из меню телефона. Его адрес: `ws://IP_ПК:8000/ws/random`. Если нужна установка/запуск из проекта:

```bash
cd ~/Unik/web_mobile_unik/lab1/lab-02/calculator
flutter-aurora devices
flutter-aurora run -d <ID_ТЕЛЕФОНА> --dart-define=WS_URL=ws://IP_ПК:8000/ws/random
```

<ID_ТЕЛЕФОНА> берите из devices. У калькулятора kirik подключение открывается значком сети в заголовке или кнопкой «Настроить подключение»; у генератора настройки видны на главной странице.

## Последовательность кадров

### 1.1. Работа web-интерфейса в браузере ПК

Имя: `lr1-01-web-result.png` (или `.jpg`).

Откройте страницу на ноутбуке. Проверьте диапазон 1…100 и генерацию числа внутри него. Сделайте один снимок формы с введёнными значениями и результатом. Требование: браузерный интерфейс на ПК и логика выбранного варианта.

### 1.2. Работа адаптивного web-интерфейса в браузере Авроры

Имя: `lr1-02-phone-browser.png` (или `.jpg`).

Откройте тот же интерфейс по HTTP-адресу ноутбука в браузере телефона и проверьте диапазон 1…100 и генерацию числа внутри него. Сфотографируйте форму с результатом при обычной вертикальной ориентации. Требование: работа в браузере Авроры и адаптация к мобильному экрану. Отдельный кадр поворота экрана не нужен.

### 1.3. Обмен мобильного приложения с сервером через WebSocket

Имя: `lr1-03-mobile-result.png` (или `.jpg`).

Откройте Flutter-приложение, задайте WebSocket-адрес из подготовки и подключитесь. Проверьте диапазон 1…100 и генерацию числа внутри него. Сделайте один кадр результата; по возможности оставьте видимым статус подключения. Требование: приложение на Авроре, подключение к серверу в локальной сети и обмен через WebSocket. Настройки отдельно снимать не нужно.

## После съёмки

Сверьте имена файлов и номера рисунков с отчётом. Проверьте читаемость каждого кадра в масштабе страницы A4. Удалите через интерфейс только собственные записи «Фото …» и синхронизируйте. Остановите серверы, запущенные вручную, если они больше не нужны. Для ЛР3 оставьте трафик на blue.
