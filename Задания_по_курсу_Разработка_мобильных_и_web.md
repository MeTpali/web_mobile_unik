Задания по курсу Разработка мобильных и web-приложений 

# **Лабораторная работа №1. Взаимодействие с web-клиентом** 

Необходимо разработать серверное программное обеспечение на любом языке программирования, реализующее логику работы в соответствии с вариантом. Данное серверное обеспечение должно взаимодействовать с пользователем посредством браузера, иметь webинтерфейс. Для реализации web-интерфейса необходимо создать файлы html, css и js. Файлы js должны обеспечивать функции управления пользовательскими действиями, обрабатывать нажатия на кнопки web-формы. Кроме того, необходимо добавить асинхронный вызов js (async, promise и т.д.). В css файле обеспечить адаптивную верстку под различные разрешения экрана с использованием @media. 

Реализованное программное обеспечение запускается в локальной сети. Демонстрируется работа приложения в браузере десктопной ОС (ПК) и в браузере мобильного телефона под управлением ОС Аврора. 

Варианты заданий: 

Вариант №1: Простой калькулятор. Пользователи вводят два числа и выбирают операцию (+, -, *, /). Результат вычисляется и выводится на экран. 

Вариант №2: Бесконечный таймер обратного отсчета. Таймер ведет обратный отсчет с указанного пользователем начального значения (например, секунд). По завершении таймера появляется сообщение о завершении. 

Вариант №3: Контактная форма обратной связи. Форма для отправки письма администратору ресурса с поля ввода имени, адреса email и сообщения. После заполнения формы данные отправляются на сервер и возвращаются обратно подтверждение отправки. 

Вариант №4: Минималистичный чат. Очень простой интерфейс чата, позволяющий отправлять короткие сообщения другим пользователям. Сообщения передаются на сервер и отображаются мгновенно всем участникам. 

Вариант №5: Преобразователь температуры. Конвертер градусов Цельсия в Фаренгейты и наоборот. Пользователь вводит температуру, выбирает единицу измерения исходной величины, нажимает кнопку преобразования, и получает результат. 

Вариант №6: Генератор случайных чисел. Программа генерирует случайное число в указанном диапазоне. Диапазон задаётся пользователем, после чего кнопка вызывает генерацию случайного числа и выводит его на экран. 

Вариант №7: Сервер статистики аналитики сайта. Простое решение для сбора статистической информации о посетителях сайта: количество просмотров страниц, уникальные посетители, длительность сессий. Данные собираются асинхронно через JS и сохраняются на сервере с визуализацией результатов в виде графиков или диаграмм. 

# **Лабораторная работа №2. Разработка мобильного клиента**

Данное приложение должно взаимодействовать с сервером посредством передачи данных через сокеты (web-сокеты). Запустить сервер на удаленном устройстве (ПК), обеспечить подключение мобильного устройства к серверу в локальной сети и взаимодействие приложения с сервером.
