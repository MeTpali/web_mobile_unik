## 2.1. Средства разработки и структура решения

Реализован генератор случайных чисел с браузерным и мобильным интерфейсами. Браузерный интерфейс использует React и Vite, HTTP API — Node.js и Express. Приложение Flutter для Авроры обращается к Python-серверу FastAPI через постоянное WebSocket-соединение. Проекты находятся в lab1/lab-01 и lab1/lab-02 и вместе составляют одну лабораторную работу.

## 2.2. Взаимодействие компонентов

Браузер отправляет асинхронный POST /api/random по относительному адресу; Express раздаёт собранный интерфейс и API с порта 3000. CSS содержит адаптивные правила @media. Flutter-клиент задаёт адрес ws://<IP-ПК>:8000/ws/random, передаёт границы в JSON, сопоставляет ответы по request_id и показывает результат и историю. UI, контроллер, модели и WebSocket-сервис разделены.

Обе границы включены; допустимы целые числа от −1 000 000 000 до 1 000 000 000. Проверяются порядок границ, формат ввода и ошибки сети; ожидание ответа ограничено тайм-аутом.

## 2.3.5. lab1/lab-01/src/App.jsx

Форма диапазона и состояния интерфейса. Проверяет ввод, асинхронно запрашивает результат, блокирует повторную отправку и отображает ошибки.

```
import { useRef, useState } from 'react';
import { requestRandom } from './api.js';

const LIMIT = 1_000_000_000;

export default function App() {

  const [min, setMin] = useState('1');
  const [max, setMax] = useState('100');

  const [pending, setPending] = useState(false);
  const [result, setResult] = useState(null);
  const [error, setError] = useState('');

  const inFlight = useRef(false);

  function changeValue(setValue, value) {
    setValue(value);
    setResult(null);
    setError('');
  }

  async function handleSubmit(event) {

    event.preventDefault();
    if (inFlight.current) return;
    setError('');
    setResult(null);

    if (!min.trim() || !max.trim()) {
      setError('Заполните оба поля диапазона.');
      return;
    }

    const lower = Number(min);
    const upper = Number(max);
    if (!Number.isInteger(lower) || !Number.isInteger(upper)) {
      setError('Минимум и максимум должны быть целыми числами.');
      return;
    }

    if (Math.abs(lower) > LIMIT || Math.abs(upper) > LIMIT) {
      setError('Границы должны быть от −1 000 000 000 до 1 000 000 000.');
      return;
    }
    if (lower > upper) {
      setError('Минимум не должен превышать максимум.');
      return;
    }

    inFlight.current = true;
    setPending(true);
    try {

      setResult(await requestRandom(lower, upper));
    } catch (failure) {
      setError(failure instanceof Error ? failure.message : 'Не удалось получить результат.');
    } finally {

      inFlight.current = false;
      setPending(false);
    }
  }

  return (
    <main className="card">
      <p className="caption">Лабораторная работа № 1 · Вариант 6</p>
      <h1>Генератор случайных чисел</h1>
      <p className="intro">Задайте диапазон целых чисел. Обе границы включаются в результат.</p>

      <form onSubmit={handleSubmit} noValidate aria-busy={pending}>
        <p id="range-hint" className="caption">Допустимые границы: от −1 000 000 000 до 1 000 000 000.</p>

        <fieldset disabled={pending}>
          <legend>Диапазон</legend>

          <div className="range-fields">
            <div className="field">

              <label htmlFor="min">Минимум</label>
              <input id="min" name="min" type="number" required step="1" min={-LIMIT} max={LIMIT}
                value={min} onChange={event => changeValue(setMin, event.target.value)}
                aria-describedby={error ? 'range-hint form-error' : 'range-hint'} />
            </div>
            <div className="field">
              <label htmlFor="max">Максимум</label>
              <input id="max" name="max" type="number" required step="1" min={-LIMIT} max={LIMIT}
                value={max} onChange={event => changeValue(setMax, event.target.value)}
                aria-describedby={error ? 'range-hint form-error' : 'range-hint'} />
            </div>
          </div>

          <button type="submit">{pending ? 'Генерация…' : 'Сгенерировать'}</button>
        </fieldset>
      </form>

      <p id="form-error" role="alert" className="error" aria-atomic="true">{error}</p>

      <section className="result" aria-live="polite" aria-atomic="true" aria-label="Результат генерации">
        {pending ? <p>Ожидаем ответ сервера…</p> : result ? <>
          <p className="result-label">Случайное число</p>
          <output>{result.value}</output>
          <p>Диапазон: от {result.min} до {result.max}</p>
        </> : <p>Введите диапазон и нажмите «Сгенерировать».</p>}
      </section>
    </main>
  );
}
```

## 2.3.6. lab1/lab-01/src/api.js

Сетевой слой клиента: POST /api/random через fetch, отмена по тайм-ауту, проверка HTTP-статуса и структуры JSON-ответа.

```
const TIMEOUT_MS = 10_000;

export async function requestRandom(min, max) {

  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), TIMEOUT_MS);

  try {
    let response;
    try {

      response = await fetch('/api/random', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ min, max }),
        signal: controller.signal,
      });
    } catch (error) {

      if (controller.signal.aborted) throw error;
      throw new Error('Не удалось связаться с сервером. Проверьте подключение и повторите попытку.');
    }

    let data;
    try {

      data = await response.json();
    } catch (error) {
      if (controller.signal.aborted) throw error;
      throw new Error('Сервер вернул некорректный ответ. Попробуйте ещё раз.');
    }

    if (!response.ok) {
      const message = data?.error?.message;
      throw new Error(typeof message === 'string' && message.trim()
        ? message
        : `Ошибка сервера (HTTP ${response.status}). Попробуйте ещё раз.`);
    }

    if (data?.min !== min || data?.max !== max || !Number.isInteger(data?.value)
      || data.value < min || data.value > max) {
      throw new Error('Сервер вернул некорректный результат. Попробуйте ещё раз.');
    }
    return data;
  } catch (error) {
    if (controller.signal.aborted) {
      throw new Error('Сервер не ответил за 10 секунд. Попробуйте ещё раз.');
    }
    throw error;
  } finally {

    clearTimeout(timeout);
  }
}
```

## 2.3.8. lab1/lab-01/server/random.js

Серверная логика: строгая проверка целых границ и генерация числа через crypto.randomInt с включением верхней границы.

```
import { randomInt } from 'node:crypto';

export const MIN_BOUND = -1_000_000_000;
export const MAX_BOUND = 1_000_000_000;

export class InvalidRangeError extends Error { }

export function generateRandom(input) {

  if (input === null || typeof input !== 'object' || Array.isArray(input)) {
    throw new InvalidRangeError('Тело запроса должно быть объектом с полями min и max');
  }

  const { min, max } = input;
  if (!Number.isInteger(min) || !Number.isInteger(max)) {
    throw new InvalidRangeError('Минимум и максимум должны быть целыми числами');
  }
  if (min < MIN_BOUND || min > MAX_BOUND || max < MIN_BOUND || max > MAX_BOUND) {
    throw new InvalidRangeError('Границы должны быть от −1 000 000 000 до 1 000 000 000');
  }

  if (min > max) {
    throw new InvalidRangeError('Минимум не должен превышать максимум');
  }

  const value = min === max ? min : randomInt(min, max + 1);
  return { min, max, value };
}
```

## 2.3.12. lab1/lab-02/backend/app/generator.py

Независимая от транспорта логика: проверка диапазона и генерация через secrets.randbelow; обе границы включены.

```
from secrets import randbelow

LIMIT = 1_000_000_000

class InvalidRange(ValueError):
    pass

def generate(minimum: object, maximum: object) -> dict:

    if type(minimum) is not int or type(maximum) is not int:
        raise InvalidRange("min и max должны быть целыми числами")
    if not -LIMIT <= minimum <= LIMIT or not -LIMIT <= maximum <= LIMIT:
        raise InvalidRange("Границы должны быть от −1 000 000 000 до 1 000 000 000")
    if minimum > maximum:
        raise InvalidRange("Минимум не должен превышать максимум")

    return {"min": minimum, "max": maximum,
            "value": minimum + randbelow(maximum - minimum + 1)}
```

## 2.3.13. lab1/lab-02/backend/app/protocol.py

Разбирает текстовый JSON, проверяет тип операции, request_id и поля. Формирует сообщения result и error.

```
import json

from .generator import InvalidRange, generate

MAX_MESSAGE_BYTES = 4096

def error(code: str, message: str, request_id=None) -> dict:

    return {"type": "error", "request_id": request_id,
            "error": {"code": code, "message": message}}

def reject_constant(value):

    raise ValueError(f"Недопустимая JSON-константа: {value}")

def handle_message(text: str) -> dict:

    if len(text.encode("utf-8")) > MAX_MESSAGE_BYTES:
        return error("MESSAGE_TOO_LARGE", "Сообщение не должно превышать 4096 байт")
    try:

        data = json.loads(text, parse_constant=reject_constant)
    except (ValueError, RecursionError):
        return error("INVALID_JSON", "Некорректный JSON")
    if not isinstance(data, dict):
        return error("INVALID_REQUEST", "Сообщение должно быть JSON-объектом")

    request_id = data.get("request_id")
    if request_id is not None and (not isinstance(request_id, str) or not 1 <= len(request_id) <= 64):
        return error("INVALID_REQUEST", "request_id должен быть строкой длиной от 1 до 64 символов или null")
    if data.get("type") != "generate":
        return error("UNKNOWN_TYPE", "Поддерживается только type: generate", request_id)

    if set(data) - {"type", "request_id", "min", "max"}:
        return error("INVALID_REQUEST", "Сообщение содержит неизвестные поля", request_id)
    try:
        result = generate(data.get("min"), data.get("max"))
    except InvalidRange as exc:
        return error("INVALID_RANGE", str(exc), request_id)

    return {"type": "result", "request_id": request_id, **result}
```

## 2.3.18. lab1/lab-02/calculator/lib/models/number_range.dart

Модель диапазона и правила проверки ввода: целые числа, предел ±1 млрд и правильный порядок границ.

```
class NumberRange {
  const NumberRange(this.minimum, this.maximum);

  static const limit = 1000000000;
  final int minimum;
  final int maximum;

  bool get isValid =>
      minimum.abs() <= limit && maximum.abs() <= limit && minimum <= maximum;

  static String? validateBound(String? text) {
    final value = int.tryParse(text?.trim() ?? '');
    if (value == null) return 'Введите целое число';
    if (value.abs() > limit) return 'От −1 млрд до 1 млрд';
    return null;
  }

  static String? validateMaximum(String? text, String minimumText) {
    final error = validateBound(text);
    if (error != null) return error;
    final minimum = int.tryParse(minimumText.trim());
    if (minimum != null && int.parse(text!.trim()) < minimum) {
      return 'Максимум должен быть не меньше минимума';
    }
    return null;
  }
}
```

## 2.3.20. lab1/lab-02/calculator/lib/services/random_service.dart

Интерфейс сервиса и реализация WebSocket-транспорта. Управляет соединением, кодирует запросы, разбирает ответы и передаёт типизированные события без зависимости от Flutter.

```
import 'dart:async';
import 'dart:convert';
import 'dart:io';

import '../models/number_range.dart';
import '../models/random_result.dart';

sealed class RandomServiceEvent {}

class RandomResponse extends RandomServiceEvent {
  RandomResponse(this.requestId, {this.result, this.error});
  final String? requestId;
  final RandomResult? result;
  final String? error;
}

class RandomConnectionLost extends RandomServiceEvent {
  RandomConnectionLost(this.message);
  final String message;
}

abstract interface class RandomService {
  Stream<RandomServiceEvent> get events;
  Future<void> connect(Uri address);
  void generate(String requestId, NumberRange range);
  void disconnect();
  void dispose();
}

class WebSocketRandomService implements RandomService {
  WebSocketRandomService(
      {this.connectionTimeout = const Duration(seconds: 10)});

  final Duration connectionTimeout;

  final _events = StreamController<RandomServiceEvent>.broadcast();
  WebSocket? _socket;
  StreamSubscription<dynamic>? _subscription;
  int _generation = 0;
  bool _disposed = false;

  @override
  Stream<RandomServiceEvent> get events => _events.stream;

  @override
  Future<void> connect(Uri address) async {
    disconnect();

    final generation = _generation;

    final pending = WebSocket.connect(address.toString());

    unawaited(pending.then((socket) {
      if (_disposed || generation != _generation) {
        unawaited(socket.close());
      }
    }, onError: (Object _) {}));
    try {
      final socket = await pending.timeout(connectionTimeout);
      if (_disposed || generation != _generation) return;
      _socket = socket;

      socket.pingInterval = const Duration(seconds: 15);

      _subscription = socket.listen(
        (frame) {
          if (generation != _generation) return;
          try {
            _events.add(_decode(frame));
          } on FormatException {
            _lost('Некорректный ответ сервера. Подключитесь снова');
          }
        },
        onError: (Object _) {
          if (generation == _generation) {
            _lost('Соединение с сервером потеряно');
          }
        },
        onDone: () {
          if (generation == _generation) {
            _lost('Сервер закрыл соединение. Подключитесь снова');
          }
        },
        cancelOnError: true,
      );
    } catch (_) {
      if (generation == _generation) disconnect();

      rethrow;
    }
  }

  @override
  void generate(String requestId, NumberRange range) {
    final socket = _socket;
    if (socket == null) throw StateError('WebSocket is not connected');

    socket.add(jsonEncode({
      'type': 'generate',
      'request_id': requestId,
      'min': range.minimum,
      'max': range.maximum,
    }));
  }

  RandomResponse _decode(dynamic frame) {
    if (frame is! String) throw const FormatException();
    final data = jsonDecode(frame);
    if (data is! Map<String, dynamic>) throw const FormatException();
    final id = data['request_id'];
    if (id != null && id is! String) throw const FormatException();

    if (data['type'] == 'error') {
      final details = data['error'];
      if (details is! Map || details['message'] is! String) {
        throw const FormatException();
      }
      return RandomResponse(id as String?, error: details['message'] as String);
    }
    if (data['type'] != 'result') throw const FormatException();
    final value = data['value'];
    final minimum = data['min'];
    final maximum = data['max'];
    if (value is! int || minimum is! int || maximum is! int) {
      throw const FormatException();
    }

    final range = NumberRange(minimum, maximum);
    if (!range.isValid || value < minimum || value > maximum) {
      throw const FormatException();
    }
    return RandomResponse(id as String?, result: RandomResult(value, range));
  }

  void _lost(String message) {
    if (_disposed) return;
    disconnect();
    _events.add(RandomConnectionLost(message));
  }

  @override
  void disconnect() {

    ++_generation;
    unawaited(_subscription?.cancel());
    _subscription = null;
    unawaited(_socket?.close());
    _socket = null;
  }

  @override
  void dispose() {
    _disposed = true;
    disconnect();

    unawaited(_events.close());
  }
}
```

## 2.3.21. lab1/lab-02/calculator/lib/controllers/generator_controller.dart

Бизнес-логика и состояние: подключение, валидация, корреляция по request_id, запрет параллельной генерации, тайм-аут и история последних десяти результатов.

```
import 'dart:async';
import 'package:flutter/foundation.dart';

import '../models/number_range.dart';
import '../models/random_result.dart';
import '../services/random_service.dart';

enum GeneratorConnectionState { disconnected, connecting, connected }

class GeneratorController extends ChangeNotifier {
  GeneratorController(
    this._service, {
    this.responseTimeout = const Duration(seconds: 10),
  }) {

    _subscription = _service.events.listen(_onEvent);
  }

  final RandomService _service;
  final Duration responseTimeout;
  late final StreamSubscription<RandomServiceEvent> _subscription;
  GeneratorConnectionState _status = GeneratorConnectionState.disconnected;
  String? _error;
  final List<RandomResult> _history = [];

  String? _requestId;
  NumberRange? _pendingRange;
  Timer? _timer;
  int _sequence = 0;

  int _generation = 0;
  bool _disposed = false;

  GeneratorConnectionState get status => _status;
  String? get error => _error;
  bool get waiting => _requestId != null;
  List<RandomResult> get history => List.unmodifiable(_history);
  RandomResult? get latestResult => _history.firstOrNull;
  bool get canGenerate =>
      _status == GeneratorConnectionState.connected && !waiting;

  Future<void> connect(String address) async {

    final uri = Uri.tryParse(address.trim());
    if (uri == null ||
        !['ws', 'wss'].contains(uri.scheme) ||
        uri.host.isEmpty ||
        uri.hasFragment ||
        uri.userInfo.isNotEmpty) {
      _error = 'Введите адрес вида ws://192.168.1.10:8000/ws/random';
      notifyListeners();
      return;
    }
    disconnect();

    final generation = _generation;
    _status = GeneratorConnectionState.connecting;
    notifyListeners();
    try {

      await _service.connect(uri);
      if (_disposed || generation != _generation) return;
      _status = GeneratorConnectionState.connected;
      notifyListeners();
    } catch (_) {
      if (_disposed || generation != _generation) return;
      _fail('Не удалось подключиться. Проверьте адрес, сеть и запуск сервера');
    }
  }

  void generate(int minimum, int maximum) {

    if (!canGenerate) return;
    final range = NumberRange(minimum, maximum);
    if (!range.isValid) {
      _error = 'Некорректный диапазон';
      notifyListeners();
      return;
    }

    _requestId = 'request-${++_sequence}';
    _pendingRange = range;
    _error = null;

    _timer = Timer(responseTimeout, () {
      _fail(
          'Сервер не ответил за ${responseTimeout.inSeconds} секунд. Подключитесь снова');
    });
    try {
      _service.generate(_requestId!, range);
    } catch (_) {
      _fail('Не удалось отправить запрос. Подключитесь снова');
      return;
    }
    notifyListeners();
  }

  void _onEvent(RandomServiceEvent event) {
    if (_disposed) return;

    if (event is RandomConnectionLost) {
      _fail(event.message);
      return;
    }

    if (event is! RandomResponse || !waiting || event.requestId != _requestId) {
      return;
    }
    final result = event.result;
    if (result != null) {
      if (result.minimum != _pendingRange!.minimum ||
          result.maximum != _pendingRange!.maximum) {
        _fail('Ответ сервера не соответствует запрошенному диапазону');
        return;
      }

      _history.insert(0, result);
      if (_history.length > 10) _history.removeLast();
    }
    _error = event.error;
    _clearRequest();
    notifyListeners();
  }

  void _clearRequest() {
    _timer?.cancel();
    _timer = null;
    _requestId = null;
    _pendingRange = null;
  }

  void _fail(String message) {
    disconnect();
    _error = message;
    notifyListeners();
  }

  void disconnect() {
    ++_generation;
    _service.disconnect();
    _clearRequest();
    _error = null;
    _status = GeneratorConnectionState.disconnected;
    if (!_disposed) notifyListeners();
  }

  @override
  void dispose() {
    _disposed = true;
    ++_generation;
    _clearRequest();

    unawaited(_subscription.cancel());
    _service.dispose();
    super.dispose();
  }
}
```

## 2.4. Запуск и проверка

Команды выполняются из каталога lab-01. npm ci устанавливает зависимости по package-lock.json, npm test запускает автоматические проверки, npm run build создаёт сборку, npm start запускает приложение.

```
cd ~/Unik/web_mobile_unik/lab1/lab-01
npm ci
npm test
npm run build
npm start
```

В браузере ПК открывается http://127.0.0.1:3000. На телефоне используется http://<IP-ПК>:3000; ПК и телефон должны иметь связь в локальной сети. Диагностический адрес /api/health возвращает {"status":"ok"}.

```
curl http://127.0.0.1:3000/api/health
curl -i http://127.0.0.1:3000/api/random \
  -H 'Content-Type: application/json' \
  -d '{"min":1,"max":100}'
```

Критерии проверки: для 1…100 возвращается целое число внутри диапазона; для −5…−5 — число −5; обратный диапазон возвращает HTTP 400. В браузере проверяются отправка кнопкой и Enter, ошибки ввода, состояние ожидания и компоновка на узком экране. В tests находятся проверки генератора, HTTP API и клиентского сетевого слоя.

Доступность API с телефона была подтверждена. При проверке веб-интерфейса на телефоне ранее наблюдалась белая страница; успешное устранение этой проблемы в материалах работы не зафиксировано. Поэтому полная демонстрация веб-интерфейса на Авроре требует отдельного подтверждения.




Сервер запускается в отдельном терминале на ПК. При первой настройке создаётся виртуальное окружение и устанавливаются зависимости:

```
cd ~/Unik/web_mobile_unik/lab1/lab-02/backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

Проверка HTTP-диагностики и консольный обмен по настоящему WebSocket:

```
curl http://127.0.0.1:8000/health

.venv/bin/python smoke_client.py
```

На телефоне включается режим разработчика и настраивается подключение Flutter. Из каталога клиента выполняются команды; идентификатор устройства берётся из вывода devices:

```
cd ~/Unik/web_mobile_unik/lab1/lab-02/calculator
flutter-aurora pub get
flutter-aurora analyze
flutter-aurora devices
flutter-aurora run -d <идентификатор-телефона>
```

В приложении указывается ws://<IP-ПК>:8000/ws/random, после чего нажимаются «Подключиться» и «Сгенерировать». Фактический IP определяется командой ip -4 addr. localhost на телефоне указывает на сам телефон, поэтому используется адрес компьютера.

Пользователем подтверждены запуск приложения на физическом TrustPhone T1 и работа обмена с Python-сервером. Критерии функциональной проверки: число внутри диапазона 1…100, отрицательные границы, фиксированный результат при 42…42, ошибка при неверном вводе, заполнение истории и восстановление после отключения сервера.

Автоматические проверки клиента разделены на тесты контроллера с подставным сервисом, проверку мобильной компоновки и обмен через локальный WebSocket. Проверки сервера находятся в backend/tests. Для Flutter для Авроры 3.41.4 документирована проблема flutter test; при её проявлении модульные и виджет-тесты запускаются через обычный Flutter SDK.
