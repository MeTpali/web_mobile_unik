# Кирик · лабораторные №1–3 · вариант №1

Самостоятельный комплект: калькулятор и список задач. Оригинальный вариант №6 находится вне этой папки и не изменён.

| Работа | Содержание | Порты | Приложение Авроры |
|---|---|---|---|
| [ЛР1](lab1/README.md) | Калькулятор в браузере и Flutter/WebSocket | 3100, 8100 | ru.kirik.calculator |
| [ЛР2](lab2/README.md) | Задачи, REST/HTTPS, SQLite, offline/конфликты | 8543 | ru.kirik.taskslab2 |
| [ЛР3](lab3/README.md) | PostgreSQL, nginx, systemd, WSS, blue-green | 9543, 9301/9302, 9401/9402 | ru.kirik.taskslab3 |

Задача содержит `title`, `description`, `status` (`todo`, `doing`, `done`) и `due_date` (YYYY-MM-DD). Вход в ЛР2/ЛР3: `demo` / `demo12345`; `viewer` имеет только чтение. Клиенты, настройки, базы и очереди ЛР2/ЛР3 раздельные.

Полная демонстрация: [ЛР1](lab1/DEMONSTRATION.md), [ЛР2](lab2/DEMONSTRATION.md), [ЛР3](lab3/DEMONSTRATION.md). Комментированные исходники и [объяснения](lab2/EXPLANATION.md) предназначены для разбора кода. [Отчёты MD/DOCX](reports/) содержат код без комментариев; данные титульника заполняются вручную. Каждая лабораторная оформлена одним отчётом.

На последней проверке ПК: 192.168.0.104; SSH телефона: defaultuser@192.168.2.16. Адреса нужно сверять через `ip -4 addr`. Сертификаты ЛР2/ЛР3 включают 192.168.0.104 и 192.168.0.118. Серверный закрытый ключ не передаётся на телефон и исключён из Git.

После разрешения пользователя ЛР1 проверена: Python/WebSocket, статический анализ Flutter и нативный сценарий на телефоне прошли. Результаты и ограничения — в lab1/docs/VALIDATION.md. Исторические результаты варианта №6 не перенесены; фактические результаты этого комплекта указаны в `lab2/docs/VALIDATION.md` и `lab3/docs/VALIDATION.md`.

Пересборка всех отчётов: `python3 tools/build_reports.py` из этой папки. Установку зависимостей, сборку и запуск см. в README соответствующей лабораторной. Снимки экрана телефона не делать: демонстрация живая, журналы — текстовые.
